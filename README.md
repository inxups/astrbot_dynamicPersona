# astrbot_plugin_dynamic_persona

通过固定指令为单条问题选择指定人格，并在插件配置页选择对应的人格。

## 使用方式

1. 先在 AstrBot 的人格管理中创建好要使用的人格。
2. 在插件配置页选择：
   - `log_persona_id`：`/log` 要使用的人格
   - `info_persona_id`：`/info` 要使用的人格
   - `fallback_reply`：没有使用斜杠指令时回复的固定内容
3. 在聊天中发送 `/log 问题` 或 `/info 问题`，插件会用对应人格回答后面的 `问题`。
4. 在聊天中发送普通内容且未使用斜杠指令时，如果配置了 `fallback_reply`，插件会直接回复这段固定内容。

插件不会修改群聊当前会话的人格，多人同时提问时互不覆盖。
